# Ведьмочка и лунная библиотека

Браузерный платформер на HTML, CSS и обычном JavaScript с Canvas, без игровых движков, npm и сборки.

## Управление
- `←` / `→` или `A` / `D` — движение.
- `Space` / `W` / `↑` — прыжок. Повторный прыжок в воздухе недоступен.
- `Shift` — магический полёт на метле, пока клавиша удерживается.
- `Esc` — пауза.
- На телефоне используются экранные кнопки.

## Правила
- Соберите три предмета: книги и коты не отнимают здоровье.
- Призраки при касании отнимают одно сердце.
- Падение в опасную зону приводит к поражению.
- Чтобы победить, соберите все три предмета и коснитесь портала.
- Рекорд хранится в `localStorage` браузера.

## Файлы
- `index.html` — разметка игры.
- `style.css` — оформление интерфейса.
- `js/main.js` — запуск, кнопки и интерфейс.
- `js/Game.js` — игровой цикл, уровень, предметы, враги и отрисовка.
- `js/Player.js` — физика и управление ведьмой.
- `js/input.js` — клавиатура и сенсорные кнопки.
- `js/collision.js` — проверка пересечений.

## Промпты, использованные для проекта
1. Создай браузерный платформер на HTML/CSS/JS на тему летающей ведьмы, без игровых движков и сборки.
2. Добавь движение, прыжок с опоры, гравитацию, платформы и столкновения сверху/снизу/сбоку;.
3. Добавь собираемые книги и котов, которые не наносят урон, а призраков, которые отнимают здоровье; добавь победу, поражение, паузу, рестарт, рекорд.
